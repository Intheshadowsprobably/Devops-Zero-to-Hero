# Day 4: AWS & Azure - How to Create Virtual Machines

**Course:** DevOps Zero to Hero  
**Topic:** Virtual Machines, Cloud Providers, and Manual Setup  
**Previous Days:** Day 0, Day 1, Day 2, Day 3  

## Overview
In this session, we cover:
1. Recap of Physical vs. Virtual Machines and Data Centers.
2. How Cloud Providers (AWS, Azure) handle VM requests.
3. Manual creation of VMs via AWS Console and Azure Portal.
4. Introduction to Infrastructure Automation (CLI, API, CFT, CDK, Terraform).

## Key Takeaways
- **VMs** are software-based computers running on physical servers.
- **Cloud Providers** abstract hardware; you request resources via UI or API.
- **AWS EC2** and **Azure VMs** are the core compute services.
- **Automation** is critical for DevOps efficiency (avoiding manual clicks for 100s of requests).
