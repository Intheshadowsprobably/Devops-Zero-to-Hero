# Day 3: Virtual Machines & Virtualization

**Course:** DevOps Zero to Hero  
**Topic:** Understanding Virtual Machines (VMs), Hypervisors, and Physical Servers  
**Goal:** To understand how virtualization improves resource efficiency in DevOps and Cloud Computing.

## 📌 Key Takeaways
1. **Efficiency is King:** DevOps aims to maximize resource usage. Virtual machines allow multiple isolated environments to run on a single physical server.
2. **The Problem with Physical Servers:** Traditionally, one application/team = one physical server. This leads to massive waste (e.g., a 100GB RAM server running a 4GB app).
3. **The Solution: Virtualization:** Using a **Hypervisor** to logically partition a physical server into multiple **Virtual Machines (VMs)**.
4. **Cloud Connection:** Cloud providers (AWS, Azure, GCP) are essentially massive data centers filled with physical servers running hypervisors to serve VMs (like EC2 instances) to users.
